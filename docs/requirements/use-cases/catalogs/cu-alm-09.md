# `CU-ALM-09` — Consultar mermas

| Sección | Información relevante |
| --- | --- |
| Identificador | `CU-ALM-09` |
| Nombre | Consultar mermas. |
| Actor | Personal de almacén o Administrador del sistema. |
| Disparador | Necesita localizar o revisar mermas y abre la opción de consulta correspondiente. |
| Precondiciones | 1. El actor inició sesión.<br>2. El actor cuenta con el permiso de consulta o reporte correspondiente. |
| Flujo principal | 1. **Actor:** abre la opción para consultar mermas **(ver E1)**.<br>2. **Nexus:** comprueba su autorización y muestra la consulta con sus criterios disponibles.<br>3. **Actor:** define los criterios que necesita y solicita aplicarlos **(ver A1)**.<br>4. **Nexus:** obtiene la información disponible **(ver EOP)** y presenta el listado con sus existencias, la acción principal para registrar una merma y la opción **Exportar Excel** **(ver A2)** **(ver A3)** **(ver A4)**.<br>5. **Actor:** selecciona la acción principal; termina `CU-ALM-09` y con esa selección dispara `CU-ALM-10` Registrar merma. |
| Flujos alternativos | **A1 — Continuar la consulta (después del paso 3):**<br>1. **Nexus:** actualiza la información y el total sin modificar datos.<br>2. **Actor:** revisa los resultados o cambia los criterios.<br>3. **Nexus:** conserva la consulta disponible; termina el caso de uso.<br>**A2 — Iniciar «Editar merma» (después del paso 4 del flujo principal):**<br>1. **Actor:** detecta datos que debe corregir en una merma y selecciona su acción de edición; termina el caso de consulta.<br>2. **Nexus:** inicia `CU-ALM-11` Editar merma y vuelve a comprobar sus precondiciones y autorización.<br>**A3 — Iniciar «Ajustar existencia de merma» (después del paso 4 del flujo principal):**<br>1. **Actor:** detecta o autoriza una diferencia de existencia de merma y abre el ajuste de stock desde la consulta de mermas; termina el caso de consulta.<br>2. **Nexus:** inicia `CU-ALM-12` Ajustar existencia de merma y vuelve a comprobar sus precondiciones y autorización.<br>**A5 — Iniciar «Agregar existencia de merma» (después del paso 4 del flujo principal):**<br>1. **Actor:** selecciona **Agregar stock**; termina la consulta.<br>2. **Nexus:** inicia `CU-ALM-13` y vuelve a validar autorización para agregar existencias de merma.<br>**A4 — Iniciar «Generar reporte de mermas» (después del paso 4 del flujo principal):**<br>1. **Actor:** desde `CU-ALM-09` Consultar mermas, selecciona **Exportar Excel** con los filtros que necesita conservar; termina el caso de consulta.<br>2. **Nexus:** inicia `CU-ALM-14` Generar reporte de mermas y vuelve a comprobar sus precondiciones y autorización. |
| Excepciones | **E1 — Acceso rechazado (después del paso 1):**<br>1. **Nexus:** comprueba las precondiciones y la autorización, determina que alguna no se cumple y rechaza la solicitud sin modificar datos ni exponer información no autorizada; comunica el motivo.<br>2. **Actor:** reconoce el rechazo; termina el caso de uso.<br>**EOP — Operación no completada (durante el paso 4 del flujo principal):**<br>1. **Nexus:** detecta que no puede obtener la información necesaria, comunica que la consulta no se completó y no modifica datos.<br>2. **Actor:** recibe el aviso y decide reintentar más tarde o terminar el caso de uso. |
| Postcondiciones (éxito y fallo) | 1. **Éxito:** Listado de existencias de merma.<br>2. **Fallo:** Un rechazo no debe producir cambios parciales ni exponer información no autorizada. |
| Requisitos relacionados | `RF-CAT-004`, `RF-WST-001`. |
