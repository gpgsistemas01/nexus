# Casos de uso — CAT

### Grupo funcional CAT — Catálogos

| Identificador | Caso de uso específico | Evidencia funcional |
| --- | --- | --- |
| `CU-CAT-01` | Consultar materiales | Listado de materiales, ofertas de proveedor y existencias. |
| `CU-CAT-02` | Crear material | Alta con presentación, unidad y relaciones válidas. |
| `CU-CAT-03` | Editar material | Actualización de datos generales admitidos. |
| `CU-CAT-04` | Retirar material | Retiro condicionado por la historia operativa. |
| `CU-CAT-05` | Ajustar existencia de material | Ajuste trazable de inventario. |
| `CU-CAT-06` | Generar reporte de inventario de materiales | Archivo Excel con filtros, columnas y cálculos propios del reporte. |
| `CU-CAT-07` | Consultar movimientos de materiales | Consulta autorizada sin modificar datos. |
| `CU-CAT-08` | Generar reporte de movimientos de materiales | Archivo Excel con filtros, columnas y cálculos propios del reporte. |
| `CU-CAT-09` | Consultar proveedores | Listado de proveedores autorizados. |
| `CU-CAT-10` | Crear proveedor | Alta con código e identidad válidos. |
| `CU-CAT-11` | Editar proveedor | Actualización de datos admitidos. |
| `CU-CAT-12` | Cambiar estado de proveedor | Activación o desactivación del proveedor. |
| `CU-CAT-13` | Generar reporte de proveedores | Archivo Excel con filtros, columnas y cálculos propios del reporte. |
| `CU-CAT-14` | Consultar clientes | Listado de clientes autorizados. |
| `CU-CAT-15` | Crear cliente | Alta con asesor opcional válido. |
| `CU-CAT-16` | Editar cliente | Actualización de datos y asesor opcional. |
| `CU-CAT-17` | Generar reporte de clientes | Archivo Excel con filtros, columnas y cálculos propios del reporte. |
| `CU-CAT-18` | Consultar mermas | Listado de existencias de merma. |
| `CU-CAT-19` | Registrar merma | Alta desde una plantilla material-proveedor. |
| `CU-CAT-20` | Editar merma | Actualización sin alterar su identidad física. |
| `CU-CAT-21` | Ajustar existencia de merma | Ajuste trazable de inventario de merma. |
| `CU-CAT-22` | Generar reporte de mermas | Archivo Excel con filtros, columnas y cálculos propios del reporte. |
| `CU-CAT-23` | Consultar movimientos de mermas | Consulta autorizada sin modificar datos. |
| `CU-CAT-24` | Generar reporte de movimientos de mermas | Archivo Excel con filtros, columnas y cálculos propios del reporte. |
| `CU-CAT-25` | Consultar área | Pantalla y listado independiente de Áreas, restringidos al administrador. |
| `CU-CAT-26` | Crear área | Alta de área con los campos permitidos. |
| `CU-CAT-27` | Editar área | Actualización de área con los campos permitidos. |
| `CU-CAT-28` | Consultar rol | Pantalla y listado independiente de Roles, restringidos al administrador. |
| `CU-CAT-29` | Crear rol | Alta de rol con los campos permitidos. |
| `CU-CAT-30` | Editar rol | Actualización de rol con los campos permitidos. |
| `CU-CAT-31` | Consultar presentación | Pantalla y listado independiente de Presentaciones, restringidos al administrador. |
| `CU-CAT-32` | Crear presentación | Alta de presentación con los campos permitidos. |
| `CU-CAT-33` | Editar presentación | Actualización de presentación con los campos permitidos. |
| `CU-CAT-34` | Consultar unidad de medida | Pantalla y listado independiente de Unidades de medida, restringidos al administrador. |
| `CU-CAT-35` | Crear unidad de medida | Alta de unidad de medida con los campos permitidos. |
| `CU-CAT-36` | Editar unidad de medida | Actualización de unidad de medida con los campos permitidos. |
| `CU-CAT-37` | Consultar motivo de ajuste | Pantalla y listado independiente de Motivos de ajuste, restringidos al administrador. |
| `CU-CAT-38` | Crear motivo de ajuste | Alta de motivo de ajuste con los campos permitidos. |
| `CU-CAT-39` | Editar motivo de ajuste | Actualización de motivo de ajuste con los campos permitidos. |
| `CU-CAT-40` | Consultar estado de cumplimiento | Pantalla y listado independiente de Estados de cumplimiento, restringidos al administrador. |
| `CU-CAT-41` | Crear estado de cumplimiento | Alta de estado de cumplimiento con los campos permitidos. |
| `CU-CAT-42` | Editar estado de cumplimiento | Actualización de estado de cumplimiento con los campos permitidos. |
