# 1. Propósito y alcance

Este documento aplica la [guía técnica común](../technical-code-documentation/index.md) al código
que se ejecuta en el navegador y a su composición EJS: `src/public/js`,
`src/views/pages` y `src/views/shared`. El [documento de backend](../backend-technical-documentation/index.md)
conserva rutas, controladores, servicios de dominio y persistencia. Una explicación de
frontend enlaza el [contrato API](../api-contract/index.md), pero no vuelve a declarar
permisos ni reglas de negocio que el servidor debe hacer cumplir.
