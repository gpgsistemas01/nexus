# Decisiones de arquitectura

## Propósito

Este índice reúne decisiones arquitectónicas transversales cuya justificación no debe
inferirse únicamente desde el estado actual de los diagramas. La descripción de
arquitectura conserva la solución vigente; cada ADR registra el contexto, las opciones y
las consecuencias de una elección relevante.

## Registros

| Identificador | Estado | Decisión |
| --- | --- | --- |
| [ADR-001](ADR-001-secuencias-por-perspectiva-y-grupo.md) | Aceptada | Organizar las secuencias por perspectiva técnica y grupo funcional. |

## Convención

Los registros usan `ADR-NNN-titulo.md` y contienen estado, contexto, opciones, decisión y
consecuencias. Una decisión reemplazada permanece versionada, cambia su estado y enlaza
el ADR que la sustituye.
