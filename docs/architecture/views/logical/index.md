# Vista lógica

## Contenido

La vista lógica responde qué dominios, componentes, estados y datos colaboran:

1. [Componentes y reutilización](01-components-and-reuse.md): capas, dependencias y
   puntos de reutilización de frontend y backend.
2. [Identidad, acceso y auditoría](02-identity-access-and-audit.md): separación entre
   cuenta, persona, autorización y actor de una escritura.
3. [Colaboraciones de componentes por capacidad](03-component-collaborations-by-capability.md):
   interfaces provistas y requeridas en los recorridos que coordinan varios dominios o
   mecanismos de inventario.
4. [Modelo persistente](data-and-persistence/index.md): diagramas ER y diccionario
   técnico derivados de Prisma.

El modelo conceptual del negocio permanece en requisitos; esta vista no duplica su
significado funcional.
