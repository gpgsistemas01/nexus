# Vista de desarrollo

## Contenido

La vista de desarrollo responde cómo se organiza el código de frontend y backend. El
[mapa generado del código](code-map.md) presenta el inventario de rutas, dependencias entre áreas y
exportaciones detectadas desde `src`.

El mapa es una referencia generada, no un capítulo editorial; por eso conserva un nombre
descriptivo sin prefijo numérico. Las explicaciones curadas permanecen en la
[documentación técnica del código](../../technical-code-documentation/index.md) y los
[diagramas vigentes](../../code-diagrams/index.md).
