# 8. CAP-CAT-SUP-02-CREATE — Formulario alta

**Casos de uso:** `CU-CAT-02` — Crear proveedor.

**Errores posibles:** [Validación de formularios](../../error-messages.md#errores-validacion), [Catálogos e inventario](../../error-messages.md#errores-catalogos).

**Controles que debe usar:** Opción **Nuevo proveedor** del selector de una compra autorizada o botón **Nuevo proveedor** del listado de Sistemas; campos **Razón social**, **Nombre comercial** y **Teléfono**; casilla **Activo** y botón **Guardar**.

1. Desde Almacén, abra **Nueva compra**, escriba el proveedor que no existe en el selector y elija **Nuevo proveedor**. Desde Sistemas también puede seleccionar el botón **Nuevo proveedor** del listado independiente. Antes de continuar, compruebe que la pantalla mostrada coincida con la captura:

   ![CAP-CAT-SUP-02-CREATE: formulario alta](../../images/suppliers/02-form-creation.png)

2. Complete los campos **Razón social**, **Nombre comercial** y **Teléfono**, y revise la casilla **Activo**.
3. Seleccione el botón **Guardar** para registrar el proveedor.
