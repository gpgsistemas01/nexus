# 12. CAP-REP-ENT-CON-06-EXPORT — Exportar compras de consumibles

**Caso de uso:** `CU-ENT-12` — Generar reporte de compras de consumible.

1. Abra **Compras → Consumibles** y aplique los filtros necesarios.
2. Seleccione **Exportar Excel**; para el informe mensual indique el mes cuando corresponda.
   ![CAP-REP-ENT-CON-06-EXPORT: exportación de compras de consumibles](../../images/purchases/12-consumables-export-report.png)
3. Abra `reporte_compras_consumibles.xlsx` y compruebe el detalle, los totales por proveedor y el resumen por consumible.

La exportación se obtiene desde la ruta exclusiva de consumibles y no incluye compras de materiales.
