# 7. CAP-ENT-CON-01-LIST — Listado de compras de consumibles

**Caso de uso:** `CU-ENT-07` — Consultar compras de consumible.

1. Abra **Compras → Consumibles**.
   ![CAP-ENT-CON-01-LIST: listado de compras de consumibles](../../images/purchases/07-consumables-list.png)
2. Use el buscador o los filtros de fecha, proveedor y persona que recibe.
3. Seleccione **Buscar / filtrar** para consultar exclusivamente compras de consumibles.
4. Desde la tabla puede abrir una compra, iniciar **Nueva compra** o generar el reporte de consumibles.

El folio pertenece a la serie común `REC`; por eso puede haber saltos respecto del listado de materiales.
