# Rendimiento, capacidad y costos

1. Consulta `back/docs/testing/backend-performance.md` y reutiliza los benchmarks y fixtures del backend. Define la carga, datos, entorno y objetivos antes de medir.
2. Registra condiciones reproducibles, latencia, errores, throughput y uso de recursos relevantes. Si consultas métricas operativas, confirma previamente autorización y alcance.
3. Compara mediciones bajo condiciones equivalentes e identifica saturación y margen. Para dimensionar, incorpora almacenamiento, respaldos, tráfico, observabilidad y operación con fuentes y supuestos explícitos.
4. Entrega resultados medidos, límites de comparación y decisiones que requieran aprobación.
