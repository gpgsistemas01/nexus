# Análisis funcional

1. Localiza en `front/docs/index.md` los requisitos, casos de uso y contratos. Contrasta lo documentado con el flujo Vue, la API, los permisos y las pruebas vigentes.
2. Identifica actores, precondiciones, estados, entradas, efectos y casos límite. Señala las diferencias entre requisito, implementación y evidencia.
3. Define el alcance, la reutilización posible y los criterios de aceptación observables. Presenta las decisiones funcionales o arquitectónicas pendientes antes de implementarlas.
4. Entrega los enlaces a requisitos, decisiones, componentes, contratos y pruebas que soportan cada conclusión.
