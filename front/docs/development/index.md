# Entorno y flujo de trabajo

Estas guías permiten preparar el equipo, ejecutar Vue y la API, comprobar un cambio
y construir la entrega. Los comandos indican su directorio de ejecución y los
archivos locales que necesita cada proceso.

| Tarea | Procedimiento |
| --- | --- |
| Preparar una copia por primera vez | [Instalación, archivos de entorno, Prisma, arranque y diagnóstico](01-getting-started.md). |
| Configurar el editor o ejecutar una comprobación | [Herramientas y comandos del frontend](02-tooling.md). |
| Compilar y publicar el sitio | [Build, proxy, cookies, Docker y hosting estático](03-build-and-deployment.md). |
| Preparar la revisión de una entrega | [Controles y evidencia según el cambio](04-change-review.md). |

El [README](../../README.md) ofrece el inicio rápido. Para entender cómo se organiza
la implementación, comienza por la [incorporación al código](../architecture/views/development/developer-onboarding.md)
y la [vista de desarrollo](../architecture/views/development/index.md): allí se
describen unidades de código, dependencias y mecanismos reutilizados.
