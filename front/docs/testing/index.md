# Pruebas del frontend Vue

Esta colección permite diseñar, ejecutar y revisar las pruebas del cliente.
Los requisitos que se comprueban están en la [especificación](../requirements/index.md).

| Necesidad | Documento |
| --- | --- |
| Elegir nivel, riesgo y técnica | [Plan de pruebas](01-test-plan.md). |
| Consultar condiciones que se deben cubrir | [Diseños por ámbito](02-test-design.md). |
| Revisar datos, pasos y resultado esperado | [Registro de casos](03-test-cases.md). |
| Conocer la evidencia y las brechas de un caso de uso | [Cobertura funcional](04-use-case-coverage.md). |
| Entender la prueba con API y base reales | [Recorrido de sistema](05-system-tests.md). |
| Instalar, preparar archivos y ejecutar | [Archivos, credenciales y comandos](06-test-files-and-credentials.md). |
| Escribir o mantener código de pruebas | [Estándar de pruebas](07-test-standards.md). |

El plan define los formatos DP, CP y EP: diseño, caso y ejecución. Las fichas
conservan el resultado esperado; los resultados reales se guardan en CI o en la
revisión del cambio.
