# Gobierno de la documentación Vue

Esta colección define cómo redactar, comprobar y publicar la documentación del
frontend. Sus reglas se aplican a `front/docs`, con propietarios y procedimientos
locales. El lector no necesita abrir la documentación de Express para aplicarlas.

4. [Reglas del proyecto, recomendaciones y criterios de aceptación](04-conventions-and-criteria.md).
5. [Manual de usuario: fuentes, capturas y publicación](05-user-manual.md).

La [entrada general](../index.md) conserva versión, estado y alcance de la colección.
Los requisitos, el diseño, las pruebas y sus resultados tienen propósitos distintos;
no se usa un inventario generado para aprobar una decisión o requisito.
