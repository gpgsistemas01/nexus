## Cómo leer una ficha

Los pasos indican qué hace el **Actor** y cómo responde **Nexus**. Las alternativas
**A1, A2…** y las excepciones **E1, E2…** indican dónde cambia el recorrido y cómo continúa o termina.

**EOP** indica un resultado no confirmado. Si se pierde la respuesta de un guardado,
hay que comprobar qué se registró antes de repetirlo.
