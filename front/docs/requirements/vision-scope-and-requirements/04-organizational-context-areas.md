# 4. Áreas del contexto organizacional

Las áreas siguientes forman el catálogo organizacional utilizado por las asignaciones
de acceso, las responsabilidades de personas y el destino de las salidas. Su presencia no concede acceso ni implica
que todas inicien casos de uso; la autorización efectiva depende de la combinación de
rol, área y permiso.

| Área | Participación vigente en el contexto de Nexus |
| --- | --- |
| Dirección | Parte interesada de supervisión; su acceso y casos de uso permanecen pendientes de definición. |
| Acabados | Área operativa de consulta de inventario y solicitud de salidas; referencia para responsabilidades de personas. |
| Administrativo | Contexto organizacional y de catálogos autorizados. |
| Almacén y proveduría | Operación de catálogos, entradas, inventario, salidas y mermas. |
| Diseño | Referencia para responsabilidades de personas y destino de salidas, según los catálogos autorizados. |
| Instalaciones | Área operativa de consulta de inventario y solicitud de salidas; referencia para responsabilidades de personas. |
| Impresión | Área operativa de consulta de inventario y solicitud de salidas; referencia para responsabilidades de personas. |
| Router | Área operativa de consulta de inventario y solicitud de salidas; referencia para responsabilidades de personas. |
| PT/Tráfico | Área operativa de consulta de inventario y solicitud de salidas; referencia para responsabilidades de personas. |
| Servicios y vigilancia | Referencia organizacional para registros y destino de salidas; su presencia en el catálogo no atribuye acceso. |
| Sistemas | Administración de cuentas, accesos, catálogos contextuales y operaciones protegidas. |
| Taller 3D (Taller/Herrería) | Área operativa de consulta de inventario y solicitud de salidas; referencia para responsabilidades de personas. |
| Ventas y proyectos especiales | Referencia organizacional para personas y registros relacionados; ventas no tiene acceso vigente al sistema. |

Los accesos operativos vigentes corresponden a Impresión, Taller/Herrería, Acabados,
Router, PT/Tráfico e Instalaciones. Coordinador y Operador son referencias de rol;
en Instalaciones se utiliza Instalador. Auxiliar y Coordinador de Almacén pueden
consultar las salidas de todas las áreas; los accesos operativos se limitan a las
áreas asignadas y autorizadas. Los roles y áreas efectivos se reciben de la sesión.
