# Catálogo de requisitos de negocio

Los criterios de esta colección describen el comportamiento esperado del producto que consume la SPA. El estado de producto no es un resultado de ejecución del frontend. Las obligaciones exclusivamente de servidor o aún modeladas no implican una capacidad adicional de Vue. La [especificación del cliente](../client-specification.md) concreta navegación, captura y estados propios; la [cobertura](../../../testing/04-use-case-coverage.md) limita la evidencia disponible.
