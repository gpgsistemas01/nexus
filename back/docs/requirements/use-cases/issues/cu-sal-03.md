# `CU-SAL-03` — Editar encabezado de salida de material

| Sección | Información relevante |
| --- | --- |
| Identificador | `CU-SAL-03` |
| Nombre | Editar encabezado de salida de material. |
| Actor | Usuario autorizado de área operativa, Personal de almacén o Administrador del sistema. |
| Disparador | Detecta datos que debe corregir en el encabezado de una salida de material y selecciona su acción de edición. |
| Precondiciones | 1. El actor inició sesión.<br>2. El actor cuenta con el permiso de edición.<br>3. El registro objetivo existe.<br>4. El registro se encuentra en un estado que admite los cambios solicitados.<br>5. El área del documento y el área de destino pertenecen al alcance autorizado de la sesión. |
| Flujo principal | 1. **Actor:** selecciona una salida de material y abre la edición de encabezado **(ver E1)**.<br>2. **Nexus:** muestra los datos actuales y habilita sólo los campos permitidos por su estado.<br>3. **Actor:** modifica los datos contextuales y confirma **(ver A1)**.<br>4. **Nexus:** valida el estado, los participantes y las relaciones y actualiza el encabezado; conserva intactas las cantidades y existencias y confirma la actualización **(ver EOP)**. |
| Puntos de extensión | Cliente no catalogado: durante la selección del cliente del encabezado, un actor con permisos de lectura y alta de Directorio busca un nombre sin coincidencia y elige **Registrar cliente**; extensión `CU-CAT-06`, flujo A2; retorna al paso 3. |
| Flujos alternativos | **A1 — Datos inválidos (después del paso 3):**<br>1. **Nexus:** valida la información capturada, detecta datos incompletos o que no cumplen las reglas del caso y señala qué debe corregirse, sin registrar cambios.<br>2. **Actor:** corrige la información indicada y vuelve a confirmar; continúa en el paso 4 del flujo principal.<br>**A2 — Cliente no catalogado y actor con permisos de Directorio (durante la selección del cliente):**<br>1. **Actor:** escribe el nombre del cliente en el selector; cuando no aparece una coincidencia, pulsa **Registrar cliente**.<br>2. **Nexus:** conserva la captura del encabezado y abre el formulario de `CU-CAT-06`.<br>3. **Actor:** completa el alta mediante ese caso o cancela el formulario auxiliar.<br>4. **Nexus:** al confirmar el alta, selecciona el cliente activo; al cancelar o crear un cliente inactivo, conserva el encabezado sin guardarlo. Continúa en el paso 3 del flujo principal. |
| Excepciones | **E1 — Acceso rechazado (después del paso 1):**<br>1. **Nexus:** comprueba las precondiciones y la autorización, determina que alguna no se cumple y rechaza la solicitud sin modificar datos ni exponer información no autorizada; comunica el motivo.<br>2. **Actor:** reconoce el rechazo; termina el caso de uso.<br>**EOP — Operación no completada (durante el paso 4 del flujo principal):**<br>1. **Nexus:** no puede completar la operación, comunica el fallo y conserva la información anterior sin cambios parciales.<br>2. **Actor:** recibe el aviso, conserva los datos capturados cuando existe un formulario y decide reintentar más tarde o terminar el caso de uso. |
| Postcondiciones (éxito y fallo) | 1. **Éxito:** El encabezado conserva los cambios admitidos.<br>2. **Éxito:** Los detalles, las cantidades y las existencias permanecen sin cambios.<br>3. **Fallo:** Un rechazo no debe producir cambios parciales ni exponer información no autorizada. |
| Requisitos relacionados | `RF-ISS-005`. |
