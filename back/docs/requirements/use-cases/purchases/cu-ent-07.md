# `CU-ENT-07` — Consultar compras de consumible

| Sección | Información relevante |
| --- | --- |
| Identificador | `CU-ENT-07` |
| Nombre | Consultar compras de consumible. |
| Actor | Personal de almacén o Administrador del sistema. |
| Disparador | Necesita localizar o revisar compras de consumible y abre la opción de consulta correspondiente. |
| Precondiciones | 1. El actor inició sesión.<br>2. El actor cuenta con el permiso de consulta o reporte correspondiente. |
| Flujo principal | 1. **Actor:** abre la opción para consultar compras de consumible **(ver E1)**.<br>2. **Nexus:** comprueba su autorización y muestra la consulta con sus criterios disponibles.<br>3. **Actor:** define los criterios que necesita y solicita aplicarlos **(ver A1)**.<br>4. **Nexus:** obtiene la información disponible **(ver EOP)** y presenta la información autorizada y la acción principal para registrar una compra **(ver A2)** **(ver A3)** **(ver A4)** **(ver A5)**.<br>5. **Actor:** selecciona la acción principal; termina `CU-ENT-07` y con esa selección dispara `CU-ENT-08` Crear compra de consumible. |
| Flujos alternativos | **A1 — Continuar la consulta (después del paso 3):**<br>1. **Nexus:** actualiza la información y el total sin modificar datos.<br>2. **Actor:** revisa los resultados o cambia los criterios.<br>3. **Nexus:** conserva la consulta disponible; termina el caso de uso.<br>**A2 — Iniciar «Editar compra de consumible» (después del paso 4 del flujo principal):**<br>1. **Actor:** detecta datos que debe corregir en una compra de consumible y selecciona su acción de edición; termina el caso de consulta.<br>2. **Nexus:** inicia `CU-ENT-09` Editar compra de consumible y vuelve a comprobar sus precondiciones y autorización.<br>**A3 — Iniciar «Corregir consumible de una compra» (después del paso 4 del flujo principal):**<br>1. **Actor:** detecta una diferencia en un consumible de una compra y abre la corrección del detalle; termina el caso de consulta.<br>2. **Nexus:** inicia `CU-ENT-10` Corregir consumible de una compra y vuelve a comprobar sus precondiciones y autorización.<br>**A4 — Iniciar «Cancelar consumible de una compra» (después del paso 4 del flujo principal):**<br>1. **Actor:** determina que debe anular consumible de una compra y solicita la cancelación; termina el caso de consulta.<br>2. **Nexus:** inicia `CU-ENT-11` Cancelar consumible de una compra y vuelve a comprobar sus precondiciones y autorización.<br>**A5 — Iniciar «Generar reporte de compras de consumible» (después del paso 4 del flujo principal):**<br>1. **Actor:** desde `CU-ENT-07` Consultar compras de consumible, selecciona la opción para generar el reporte con los filtros que necesita conservar; termina el caso de consulta.<br>2. **Nexus:** inicia `CU-ENT-12` Generar reporte de compras de consumible y vuelve a comprobar sus precondiciones y autorización. |
| Excepciones | **E1 — Acceso rechazado (después del paso 1):**<br>1. **Nexus:** comprueba las precondiciones y la autorización, determina que alguna no se cumple y rechaza la solicitud sin modificar datos ni exponer información no autorizada; comunica el motivo.<br>2. **Actor:** reconoce el rechazo; termina el caso de uso.<br>**EOP — Operación no completada (durante el paso 4 del flujo principal):**<br>1. **Nexus:** detecta que no puede obtener la información necesaria, comunica que la consulta no se completó y no modifica datos.<br>2. **Actor:** recibe el aviso y decide reintentar más tarde o terminar el caso de uso. |
| Postcondiciones (éxito y fallo) | 1. **Éxito:** Listado y detalle sin modificar inventario.<br>2. **Fallo:** Un rechazo no debe producir cambios parciales ni exponer información no autorizada. |
| Requisitos relacionados | `RF-REC-001`. |
