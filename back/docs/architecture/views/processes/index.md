# Vista de procesos

Las [secuencias backend](backend-code-sequences/index.md) muestran la realización de
los casos de uso desde la frontera HTTP hasta servicios, transacciones y respuesta.
Cada participante técnico enlaza su archivo y cada mensaje identifica una operación.
El código y el contrato HTTP son la fuente de las llamadas y permisos.

La [interacción de extremo a extremo](01-end-to-end-interaction.md) explica las
fronteras de la solución. La [auditoría transversal](shared-runtime-behavior/index.md)
conserva su persistencia posterior a la respuesta. Las colaboraciones de componentes,
composables y servicios se mantienen en los [procesos Vue](../../../../../front/docs/architecture/views/processes/index.md).
