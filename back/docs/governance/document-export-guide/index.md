# Guía de exportación del backend

Ejecute los comandos desde `back/`. Las fuentes permanecen en `docs/`; los resultados
se generan en `build/docs/` y no se versionan.

| Herramienta | Función |
| --- | --- |
| Node.js | Ejecutar los scripts documentales. |
| Mermaid CLI y Chromium | Convertir diagramas Markdown en imágenes. |
| Pandoc | Ensamblar las fuentes y generar DOCX. |
| LibreOffice | Convertir el DOCX generado a PDF. |
